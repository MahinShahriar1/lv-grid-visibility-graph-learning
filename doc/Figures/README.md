# Paper Figures

This folder contains selected public-facing output figures from the published paper. These images are included for GitHub presentation only. Raw datasets, saved time-series CSVs, topology files, model checkpoints, and full result tables are intentionally excluded.

Included figures:

- `figure_1_training_validation.png` - training and validation MSE across phases.
- `figure_2_node445_prediction_vs_actual.png` - predicted versus simulated voltage for Node 445, Phase A.
- `figure_3_proposed_vs_baselines_mae_rmse.png` - proposed method versus baseline methods for MAE and RMSE.
- `figure_4_mvlv_distribution_system_review_before_upload.png` - MV/LV distribution test system figure. Review with the advisor before publishing if topology visibility is a concern.
- `figure_5a_zone10_hrrsm_captain_example.png` - Zone 10 HRRSM/captain selection example.
- `figure_5b_zone20_hrrsm_captain_example.png` - Zone 20 HRRSM/captain selection example.
